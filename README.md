# Trove

Share what you have, get what you need — a Telegram marketplace for communities.

## Setup

1. Clone repo
2. Copy .env.example → .env, fill values
3. `npm install`
4. `npm start`

## Commands

- `/start` — register and set location
- `/post` — share an item
- `/request <text>` — find items
- `/profile` — your items and reputation
- `/feedback <itemId> <rating>` — rate a transaction

Deployed on Railway with MongoDB Atlas.
